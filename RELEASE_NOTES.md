# Skipify 1.0.0

Skipify is an independent Android companion for Spotify. This initial release includes ad-break skipping with a mute fallback, Android Auto modes, an optional Spotify-only DNS filter, and setup through Wireless debugging, Shizuku, or root.

This build uses the Skipify app identity and removes inherited automatic update checking and APK installation. See the [README](README.md) for supported Android versions, setup steps, privacy details, and known limitations. Skipify is derived from Hush and remains licensed under GPL-3.0; see `LICENSE` for the full license and attribution in the README.

## APK notice

The accompanying release APK is the locally built, optimized **unsigned** APK. Sign it with the maintainer's private release key before distributing it as an installable app. Do not publish a signing key or signing credentials.
