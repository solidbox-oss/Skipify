# Changelog

## 1.0.0 — Initial Skipify release

- New Skipify package identity, app name, icon, and mint/deep-teal interface.
- Retains full ad-break skipping and mute fallback, Android Auto modes, Spotify-only DNS filtering,
  and setup through Wireless debugging, Shizuku, or root.
- Removes the inherited release checker, update notices, and automatic APK installer. GitHub builds
  and releases are controlled by whoever maintains the Skipify repository.

Skipify is derived from the GPL-3.0-licensed Hush source; see the attribution in [README.md](README.md).
